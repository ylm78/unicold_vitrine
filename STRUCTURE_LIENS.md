## 📊 Maillage Interne SEO

### Pages avec le plus de liens entrants (Hub Pages)
1. **Page d'accueil** (`/`) - Point d'entrée principal
2. **Page Services** (`/services`) - Hub central
3. **Page Contact** (`/contact`) - Conversion
4. **Page Devis** (`/devis`) - Conversion

### Pages cibles (Pages importantes mais moins liées)
- Pages produits individuelles
- Pages solutions par métier
- Page Réalisations

### Recommandations pour améliorer le maillage interne :

1. **Ajouter des liens contextuels** dans le contenu :
   - Dans la page Services, ajouter des liens vers les pages produits
   - Dans les pages produits, ajouter des liens vers les solutions par métier
   - Dans les réalisations, ajouter des liens vers les services correspondants

2. **Créer un fil d'Ariane (Breadcrumb)** :
   - Accueil > Services > Installation
   - Accueil > Produits > Panneaux Sandwich

3. **Ajouter des sections "Articles similaires"** :
   - Sur les pages produits : "Vous pourriez aussi être intéressé par..."
   - Sur les pages solutions : "Découvrez aussi nos autres solutions..."
